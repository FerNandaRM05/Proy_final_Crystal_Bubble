# App de Crystal Bubble

## ¿Que es Crystal Bubble?

Crystal Bubble es una marca innovadora y comprometida, dedicada a la moda solidaria y al asesoramiento de imagen como una vía para el autoconocimiento. Fundada en 2019 en Barcelona, Crystal Bubble se enfoca en ofrecer un estilo libre y auténtico para cada mujer, adaptándose a las necesidades únicas de vestimenta de cada cuerpo. 

La marca no solo proporciona moda y accesorios a través de su boutique en línea, sino que también impulsa iniciativas solidarias en apoyo a la salud de la mujer, luchando contra el cáncer mediante compras que transforman la moda en momentos únicos y felices. Crystal Bubble apuesta por normalizar el uso de la talla adecuada y hacer sentir a las clientas cómodas y seguras con su propio estilo.
## Proyecto Final

La empresa Crystal Bubble solicito a nuestro equipo realizar una app ya que como hoy en dia el dispositivo mas utilizado es el telefono movil, su objetivo era llegar a mas usuarios para que puedan expandir su mercado.

## Descripcion

Este proyecto tiene como objetivo desarrollar la interfaz de una aplicación móvil para una tienda de moda, utilizando tecnologías modernas y eficientes. La aplicación ofrece una experiencia de usuario fluida y atractiva, centrada en facilitar la interacción con la tienda y sus productos. La interfaz incluye cuatro secciones principales: `Home, Contacto, Menú y Pasos Introductorios`, cada una diseñada para proporcionar información clave y mejorar la experiencia del usuario.

### Secciones Principales
#### Home

- Descripción General: La sección Home proporciona una visión general del propósito y la esencia de la tienda.
- Pedir Cita: Una funcionalidad que permite a los usuarios solicitar una cita para visitar la tienda física.
- Artículos Nuevos: Un listado de los productos más recientes disponibles en la tienda.
- Exclusivas: Productos exclusivos disponibles solo para ciertos clientes o en cantidades limitadas.
- Ofertas: Promociones y descuentos actuales que los usuarios pueden aprovechar.
### Contacto

- Mapa Interactivo: Un mapa dinámico que muestra la ubicación de la tienda física, similar a Google Maps. Este mapa es interactivo, permitiendo a los usuarios navegar y encontrar la tienda fácilmente.
- Formulario de Contacto: Un formulario donde los usuarios pueden enviar consultas, comentarios o solicitudes directamente a la tienda.
- Redes Sociales: Enlaces a las redes sociales de la tienda para que los usuarios puedan seguir y mantenerse actualizados con las novedades y promociones.
### Menú

- Marca: Información sobre la marca, su filosofía y lo que la diferencia en el mercado.
- Comunidad de Moda: Un espacio dedicado a la comunidad de moda que rodea a la tienda, incluyendo eventos, colaboraciones y noticias.
- Ventas: Información detallada sobre las ventas, incluyendo los productos más populares y los bestsellers.
- Blog: Acceso al blog de la tienda, donde se publican artículos sobre tendencias de moda, consejos de estilo, y noticias de la industria.
### Pasos Introductorios

- Guía de Bienvenida: Una breve introducción que da la bienvenida a los nuevos usuarios y explica la finalidad de la aplicación.
- Consejos Útiles: Sugerencias y recomendaciones diseñadas especialmente para personas mayores, enfocándose en cómo aprovechar al máximo la aplicación.

### Tecnologías Utilizadas
- **Ionic/React.js**: Para la estructura y funcionalidad de la aplicación, permitiendo un desarrollo multiplataforma eficiente y la creación de interfaces de usuario dinámicas.
- **HTML**: Para la estructura del contenido en la aplicación.
- **CSS**: Para el diseño y estilo de la aplicación, asegurando una presentación visualmente atractiva y coherente.
- **TypeScript**: Para una programación más segura y eficiente, proporcionando tipos estáticos sobre JavaScript.
#### Objetivo del Proyecto
El objetivo principal de este proyecto es proporcionar una interfaz de usuario intuitiva y funcional para una aplicación de carrito de compras, optimizando la experiencia de los clientes al interactuar con la tienda y sus productos. Esta interfaz permitirá a los usuarios navegar fácilmente por la aplicación, obtener información relevante y realizar acciones clave como pedir citas, explorar nuevos productos, aprovechar ofertas y contactar con la tienda.

Con una implementación cuidadosa y un diseño centrado en el usuario, la aplicación busca mejorar la satisfacción del cliente y fomentar una mayor interacción con la tienda y su comunidad.


## Instalacion
#### Prerrequisitos

Antes de comenzar, asegúrate de tener instalados los siguientes software en tu máquina:

- **Node.js**: Puedes descargar e instalar Node.js desde [nodejs.org](https://nodejs.org/).
- **npm**: Node.js incluye npm (Node Package Manager).

Sigue estos pasos para instalar y configurar el proyecto en tu entorno local:

1. **Instalar Ionic CLI**

   Abre tu terminal y ejecuta el siguiente comando para instalar Ionic CLI globalmente:

   ```sh
   npm install -g @ionic/cli
2. Clonar el Repositorio

    ```sh
    git clone https://github.com/usuario/nombre-del-repositorio.git
    cd nombre-del-repositorio
3. Instalar Dependencias

   Una vez dentro del directorio del proyecto, instala las dependencias necesarias ejecutando:
   ```sh
    npm install
4. Ejecutar la Aplicación

   Inicia el servidor de desarrollo ejecutando:
   ```sh 
   ionic serve
   ```
   tambien podrias utilizar
    ```sh
    npm start
